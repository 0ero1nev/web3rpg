# Persona artwork

Place final character artwork here as WebP files using these exact names:

- `newton.webp`
- `icarus.webp`
- `midas.webp`
- `sisyphus.webp`
- `don-quixote.webp`
- `caesar.webp`
- `napoleon.webp`
- `croesus.webp`
- `diogenes.webp` (special ninth persona)

Recommended source ratio: approximately 4:3 landscape. The card crops artwork with `object-fit: cover`.
